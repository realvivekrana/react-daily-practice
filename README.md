# ⚛️ React Daily Practice

A dedicated repository to learn, practice, and strengthen my React.js skills through daily coding, hands-on exercises, and small projects.

My goal is to build a strong foundation in React, write clean and reusable components, and become confident in developing modern frontend applications.

## 🎯 Learning Goals

- Understand React fundamentals and component-based architecture.
- Practice JSX, props, state, and event handling.
- Learn React Hooks, including `useState` and `useEffect`.
- Understand conditional rendering and list rendering.
- Work with forms, controlled components, and validation.
- Learn React Router for navigation between pages.
- Fetch and manage data using REST APIs.
- Improve code readability, debugging, and problem-solving skills.
- Build practical projects to strengthen frontend development skills.

## 🚀 Getting Started

### Prerequisites

Install the following on your computer:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/realvivekrana/react-daily-practice.git
```

### 2. Navigate to the project

```bash
cd react-daily-practice
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

### 5. Build for production

```bash
npm run build
```

### 6. Run the code quality check

```bash
npm run lint
```
